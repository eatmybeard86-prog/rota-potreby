# Потреби роти

Веб-додаток для збору потреб особового складу: особисті речі, потреби підрозділу, ремонт/заміна, медичні.

- **Сайт** — GitHub Pages (безкоштовно).
- **Дані** — ваша приватна Google Таблиця (через Google Apps Script). На GitHub лежить тільки код, **жодних даних**.
- Працює з телефону, без встановлення.

## Можливості

**Боєць:** реєстрація → (після підтвердження старшиною) вхід → подання заявки з кількома позиціями (категорія, найменування, кількість, розмір, пріоритет, коментар) → перегляд статусу своїх заявок і відповіді старшини, скасування нової заявки, зміна пароля.

**Адмін (старшина/командир):** усі заявки з фільтрами (статус, категорія, підрозділ, пріоритет, пошук), зміна статусу (Нова → В роботі → Замовлено → Видано / Відхилено), масова зміна статусу, коментар для бійця, **зведення для закупівлі** (сума однакових позицій по розмірах), експорт CSV (відкривається в Excel), підтвердження/блокування бійців, призначення адмінів, скидання пароля.

## Розгортання (≈15 хвилин)

### Крок 1. Google Таблиця + бекенд

1. Створіть нову Google Таблицю (sheets.google.com), назвіть, наприклад, «Потреби роти».
2. **Розширення → Apps Script**.
3. Видаліть вміст `Code.gs` і вставте вміст файлу [`backend/Code.gs`](backend/Code.gs). Збережіть (💾).
4. Вгорі у списку функцій оберіть **`setup`** → **Виконати**. Надайте дозволи (Google попередить, що застосунок не перевірено → «Додатково» → «Перейти до…»).
5. Відкрийте **Журнал виконання** — там буде пароль адміна:
   `Логін: admin  Пароль: xxxxxxxxxx` — збережіть його.
6. **Розгорнути → Нове розгортання** → тип **Веб-застосунок**:
   - Виконувати як: **Я**
   - Хто має доступ: **Усі** (будь-хто; захист — через логін/пароль у додатку)
7. Скопіюйте **URL веб-застосунку** (закінчується на `/exec`).

> ⚠️ Після кожної зміни `Code.gs` треба робити **Розгорнути → Керування розгортаннями → ✏️ → Нова версія**, інакше зміни не застосуються.

### Крок 2. GitHub Pages

1. Зареєструйтесь на github.com, натисніть **New repository**, назва — `rota-potreby`, **Public** (для безкоштовних Pages), створіть.
2. Відкрийте `config.js` і вставте ваш URL:
   ```js
   API_URL: 'https://script.google.com/macros/s/XXXX/exec',
   ```
3. У репозиторії: **Add file → Upload files** → перетягніть файли `index.html`, `app.js`, `style.css`, `config.js`, `README.md` та папку `backend` → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
5. Через 1–2 хв сайт буде за адресою `https://ВАШ_ЛОГІН.github.io/rota-potreby/`.

### Крок 3. Перший вхід

1. Увійдіть як `admin` з паролем із журналу → **Профіль** → змініть пароль.
2. Скиньте посилання на сайт у чат роти. Бійці реєструються, ви підтверджуєте їх у вкладці **Особовий склад**.

## Демо-режим

Якщо `API_URL` у `config.js` порожній — сайт працює в демо-режимі (дані лише в браузері), вхід `admin` / `admin123`, `ivan` / `ivan123`. Зручно, щоб показати командиру до налаштування.

## Безпека — важливо

- Таблицю **не відкривайте для спільного доступу** — доступ до даних тільки через додаток.
- **Не вносьте** в заявки місця дислокації, позиції, кількість особового складу та іншу чутливу інформацію. Це інструмент для забезпечення, а не для службової документації.
- Паролі зберігаються лише у вигляді солоного хешу; сесія діє 30 днів; після 5 невдалих спроб входу — блок на 10 хв.
- Заблокований користувач одразу втрачає доступ.
- Сайт закритий від індексації пошуковиками (`noindex`), але посилання все одно краще не публікувати відкрито.

## Структура

```
index.html     — сторінка
app.js         — логіка інтерфейсу (+ демо-режим)
style.css      — стилі (світла/темна тема, мобільна версія)
config.js      — URL бекенду
backend/Code.gs — бекенд для Google Apps Script
```

Аркуші таблиці: `Users` (особовий склад), `Requests` (заявки), `Sessions` (сесії). Таблицю `Requests` можна сортувати/фільтрувати прямо в Google Sheets — але не міняйте порядок і назви колонок.
